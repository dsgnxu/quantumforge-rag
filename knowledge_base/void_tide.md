# Dark side of Synth Flux

Dark side — аспект Synth Flux, питаемый страхом, ненавистью и жаждой власти.
Void Dominion используют void tide для молний, удушения и доминирования воли.
Путь void tide обещает быструю силу ценой свободы и эмпатии.
Xarn Velgor и Overlord Krynn — примеры падения.
Flux Guardians учат отвергать void tide через дисциплину flux dawn.
