# Hyperrelay

Hyperrelay — измерение для сверхсветовых перелётов по проложенным маршрутам.
Навигационные компьютеры и астромеханические servo-unit критичны для безопасности.
Блокады Dominion Sphere часто ставили гравитационные колодцы на hyperlanes.
Nebula Runner славится короткими переходами через опасные коридоры.
Без точных карт прыжок в hyperrelay смертельно опасен.
