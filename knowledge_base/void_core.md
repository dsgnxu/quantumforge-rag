# Void Core

Void Core — боевая станция Dominion Sphere, способная уничтожить планету одним выстрелом.
Оснащена суперлазером и защищена флотом Void Cruiser и Shade Dart.
Планы станции были украдены Free Concord при участии Seren Vahl.
Kael Orin уничтожил первую Void Core, попав в реактор через Synth Flux.
Позже Dominion Sphere строила вторую станцию над Verdance.
