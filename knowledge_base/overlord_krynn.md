# Overlord Krynn

Overlord Krynn, также известный как Overlord Krynn, — Void Sovereign и правитель Dominion Sphere.
Манипулировал сенатом и развязал Replica Wars, чтобы уничтожить Flux Guardians.
Создал Dominion Sphere и проект Void Core как инструмент страха.
Использует lightning void tide и скрывает личность Void Dominion за политической маской.
Его цель — абсолютный контроль через void tide и военную мощь Dominion Sphere.
